# קטלוג מחשבי Dell - כלי סינון ובקשת הצעת מחיר בוואטסאפ

כלי עצמאי (לא תלוי בוורדפרס) שמאפשר ללקוחות לסנן מתוך קטלוג מחשבי ה-Dell
שמשווקים דרך הספק CMS (cms.co.il), ולשלוח בקשת הצעת מחיר מוכנה בוואטסאפ
ישירות מהמכשיר שלהם.

הפרויקט מורכב משני חלקים:

1. **סקריפט סקרייפינג** (`scraper/scrape.js`) - אוסף את כל מוצרי ה-Dell
   מאתר CMS וכותב אותם ל-`site/data/products.json`.
2. **אתר סטטי** (`site/`) - HTML/CSS/JS פשוט (בלי React, בלי בילד),
   שקורא את `products.json` ומציג ממשק סינון וחיפוש עם כפתורי וואטסאפ.

---

## התקנה ראשונית

צריך [Node.js](https://nodejs.org) גרסה 18 ומעלה מותקן במחשב. לבדוק עם:

```bash
node --version
```

לאחר מכן, בתוך תיקיית הפרויקט (`dell-catalog-app`), מתקינים את התלויות
(פעם אחת בלבד, או כשעוברים למחשב חדש):

```bash
npm install
```

---

## איך מריצים את הסקרייפר (עדכון הקטלוג)

בכל פעם שרוצים לרענן את רשימת המוצרים (מוצרים חדשים, שינויי מלאי וכו'):

```bash
npm run scrape
```

מה קורה בפועל:

- הסקריפט עובר על כל עמודי הקטגוריה `laptop-pc/brand-dell` באתר cms.co.il
  (מזהה אוטומטית כמה עמודים יש).
- בין כל בקשה לעמוד הבא יש המתנה של 1-2 שניות, כדי לא להעמיס על השרת.
- התוצאה נכתבת ל-`site/data/products.json`.
- **אין מחירים בקובץ** - האתר של הספק לא חושף מחירים בלי התחברות, ולכן
  זה לא נאסף ולא אמור להופיע.

### בקרת תקינות (safety check)

אם מספר המוצרים שנאספו קטן משמעותית (פחות מ-90%) ממה שהיה בקובץ הקודם,
הסקריפט **לא ידרוס** את `products.json` הקיים. הוא ידפיס אזהרה בקונסול,
וישמור את התוצאה החדשה בקובץ נפרד בשם `site/data/products.rejected.json`
כדי שתוכלו לבדוק ידנית מה קרה (למשל שהאתר של הספק שינה את מבנה העמוד).

אם זה קורה: פתחו את `products.rejected.json`, בדקו שהנתונים הגיוניים,
ואם הכל תקין - פשוט העתיקו/שנו שם את הקובץ ל-`products.json`.

## איך מעדכנים את "המוצרים המומלצים"

בקובץ `site/data/recommended-skus.json` יש רשימה פשוטה של מק"טים (SKU)
שמסומנים בתג "מומלץ" בכרטיס המוצר. אפשר לערוך את הקובץ ישירות בכל עורך
טקסט (גם Notepad):

```json
["LT-RD33-16991", "AL-RD33-16656"]
```

- אפשר לשים עד 20 מק"טים (או כמה שרוצים - זו רק המלצה).
- את המק"ט של כל מוצר אפשר לראות בכרטיס שלו באתר, או בקובץ `products.json`.
- שינוי בקובץ הזה לא דורש הרצה מחדש של הסקרייפר - רק לרענן את דף האתר.

## איך מריצים את האתר לבדיקה מקומית

```bash
npm run serve
```

זה יפתח שרת מקומי (בכתובת שתוצג בטרמינל, בדרך כלל
`http://localhost:5173`) שמגיש את תיקיית `site`. אפשר גם פשוט לפתוח את
`site/index.html` ישירות בדפדפן, אבל שרת מקומי קטן עדיף כדי שהדפדפן יטען
את קובצי ה-JSON בלי בעיות הרשאות.

## איך מפרסמים גרסה מעודכנת של האתר

האתר הוא תיקיית `site/` בלבד - קבצים סטטיים (HTML/CSS/JS + שני קבצי JSON).
כל שירות אחסון סטטי (Netlify, Vercel, GitHub Pages וכו') יכול להגיש אותה
ישירות בלי צורך בבנייה (build).

**זרימת עבודה מומלצת בכל עדכון:**

1. `npm run scrape` - לרענן את הקטלוג (אם צריך).
2. לעדכן את `recommended-skus.json` (אם צריך).
3. להעלות/לפרסם מחדש את תיקיית `site` בשירות האחסון שבחרתם (למשל גרירת
   התיקייה ל-Netlify, או `git push` אם השירות מחובר לריפו).

### המלצה: שילוב באתר הוורדפרס

יש שתי דרכים לשלב את הכלי הזה באתר הוורדפרס הקיים:

1. **אירוח חיצוני + קישור/כפתור בתפריט** - האתר הסטטי רץ בכתובת נפרדת
   (למשל `dell.yourdomain.co.il` או כתובת של Netlify/Vercel), ובתפריט
   הוורדפרס מוסיפים קישור רגיל אליה.
2. **הטמעה ב-iframe** - יוצרים עמוד וורדפרס רגיל ומטמיעים בו
   `<iframe>` שמצביע לאותה כתובת מתארחת.

**ההמלצה שלי: אפשרות 1 (קישור חיצוני), לא iframe.**

הסיבות:

- **מובייל** - רוב הגולשים מגיעים מהנייד, ו-iframe בתוך עמוד וורדפרס
  יוצר לרוב גלילה כפולה (גם של העמוד וגם של ה-iframe) וחוויית שימוש
  מסורבלת, בעיקר עם פאנל סינון שצריך גם הוא מקום לגלול.
- **קישורי וואטסאפ** - חלק מהדפדפנים/וובויוז בתוך אפליקציות (למשל
  פייסבוק, אינסטגרם) חוסמים או מתנהגים בצורה לא צפויה עם `wa.me` בתוך
  iframe מוטמע. קישור ישיר לעמוד עצמאי נפתח בדפדפן מלא, ושם `wa.me`
  עובד בלי בעיות.
- **תחזוקה** - עדכון האתר העצמאי (פרסום מחדש של `site/`) לא תלוי
  בגרסת וורדפרס, תוספים או תבנית, ולא יכול "לשבור" משהו אחר באתר.
- העלות/מורכבות של קישור רגיל מהתפריט זהה כמעט לגמרי ל-iframe - שתי
  האפשרויות דורשות רק להעלות דומיין/כתובת אחת.

כלומר: מפרסמים את `site/` באירוח סטטי (Netlify/Vercel/GitHub Pages),
ומוסיפים כפתור/קישור רגיל בתפריט הוורדפרס לכתובת הזו.

## מבנה הפרויקט

```
dell-catalog-app/
  package.json
  scraper/
    scrape.js              # סקריפט הסקרייפינג
  site/                     # האתר הסטטי - זו התיקייה שמפרסמים
    index.html
    styles.css
    app.js
    data/
      products.json         # פלט הסקרייפר - לא עורכים ידנית
      recommended-skus.json  # רשימת מק"טים מומלצים - עורכים ידנית
```
